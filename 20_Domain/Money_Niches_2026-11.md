# Ниши для заработка из Грузии без регистрации бизнеса (ноябрь 2026)

## Summary

Поиск 2026-11-21 по запросу Дениса: где он (физлицо в Грузии, без ИП и самозанятости) может быстро заработать на том, что делает Claude, и где ниша почти не занята. Три направления: биржи фриланса, площадки цифровых товаров, незакрытые потребности в Telegram у русскоязычных в Грузии и в СНГ. Яндекс Игры на паузе — [[20_Domain/Yandex_Games_Market_2026-11]].

## Details

### Как получать деньги из Грузии

- Payoneer — основной путь (Fiverr, Upwork, itch.io, Etsy, Freemius). Для грузинского адреса нужна выписка банка или счёт за коммуналку; ВНЖ сам по себе не подходит (payoneer.com/ru/resources/proof-of-residence).
- Stripe Грузию не поддерживает → отпадают Notion, Figma, Roblox Creator Store, Payhip, ExtensionPay. PayPal на приём в Грузии — данные противоречат, не рассчитывать. Gumroad — только PayPal для Грузии. Lemon Squeezy закрывается (2027-03-31), Envato не принимает новых авторов.
- Свои продажи (сайт, расширение): Dodo Payments (Грузия в списке, 4% + 40¢) или Paddle.
- Telegram Stars: ~$0.013 за звезду разработчику, вывод через Fragment с проверкой паспорта, звёзды доступны через 21 день.
- Kwork.ru с осени 2026 только для граждан РФ со статусом самозанятого/ИП и российской картой (FAQ Kwork, обновлено 2026-11-20); иностранцам — Kwork.com (SumSub, вывод на карту 12%). FL.ru платит нерезидентам только на карты РФ/Казахстана или МИР.

### Спрос (официальные индексы)

- Fiverr Business Trends Index (2026-06-09, поиски ноябрь 2025 — апрель 2026): специалисты Claude Code +938%, n8n-автоматизации с ИИ +125%, vibe coding +61%, голосовые ИИ-агенты +49%.
- Upwork In-Demand Skills 2026: ИИ-интеграция +178%, ИИ-чат-боты +71%, извлечение данных в топ-10. Грузия не в списке запретов Upwork; отклик $0.15.
- Kwork 2025: в «Разработке и IT» ~5620 проектов в месяц, новички без рейтинга взяли 29,6% заказов.

### Незанятые ниши с доказательствами

- Русскоязычные в Грузии: ~38 тыс. граждан РФ по переписи 2024 (оценка 2026 — ~72 тыс.); крупнейшие чаты @Mybatumi_chat 30,9 тыс., @Mytbilisi_chat 24,9 тыс., @ipgeorgiachat 24,6 тыс. (6,4 тыс. онлайн).
- ИП / разрешение на работу (с 2026-03-01 нужно большинству иностранцев, штраф от 2000 GEL) — самая сильная боль; ИИ-консультанта нет, люди платят бухгалтерам 100–200 GEL/мес, админы @ipgeorgia продают помощь через бота.
- ИИ-тьютор грузинского для русскоязычных — продукта не найдено, спрос не подтверждён.
- Алерты аренды — ниша занята (@georgia_aparts_bot с платной подпиской), API нет, Cloudflare.
- Наборы под модерацию Яндекс Игр (HTML5): в августе 2026 подано 17,1 тыс. игр, 74% отклонено (пересказ wnhub); на itch.io около двух платных шаблонов с Yandex SDK. Риск: Яндекс сейчас не принимает новые игры; покупатели из РФ не могут платить картами на itch.io.
- Отвергнуто: инструменты для селлеров WB/Ozon (красный океан, оплата из РФ), кросспостинг Telegram→Max (занято), шаблоны ботов на Stars (много бесплатного кода).

### Рекомендация Claude (2026-11-21)

1. Быстрые деньги: Fiverr + Upwork — ИИ-автоматизации (n8n/Make + LLM), ИИ-чат-боты для бизнеса, парсинг и чистка данных. Claude делает работу и пишет тексты, Денис общается и сдаёт.
2. Свой продукт: Telegram-бот «ИП, налоги и разрешение на работу в Грузии» с ИИ (подписка Stars; выход к аудитории через админов @ipgeorgia или платные посты).
3. Дальше: ИИ-тьютор грузинского; набор для модерации Яндекс Игр на itch.io (80% уже есть в `RobloxGame/shared/platform`).
