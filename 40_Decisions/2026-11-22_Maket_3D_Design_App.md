# 2026-11-22 «Макет»: 3D-приложение для дизайна интерьера и планировки

## Context

- 2026-11-22 Денис описал идею: приложение для дизайна — добавлять модели, подбирать цвета, «для моделирования и архитектуры»; примеры искать на GitHub и брать оттуда; выглядеть «максимально не иишно», в 3D, «очень круто». Позже добавил: импорт моделей разных видов (например со Sketchfab); менять сцены, комнаты и свет; воссоздавать свою квартиру; потом нужен красивый exe; есть ключ GLM 5.3 Flash — использовать, если будет смысл. Решения принимает Claude сам, Денис не у ПК.

## Options

- Форк `pascalorg/editor` (MIT, ~25 тыс. звёзд, React Three Fiber + WebGPU, Next.js, свой сервер): сразу много функций, но это чужой продукт с новой вывеской, тяжёлая кодовая база и нужен сервер.
- Своё приложение на three.js, статическое: меньше функций на старте, зато свой вид, работает как страница и оборачивается в exe. Выбрано.

## Decision

- Своё статическое веб-приложение «Макет»: TypeScript + Vite + three.js без фреймворков. Проект — неизменяемый документ, логика в чистых функциях с тестами.
- Планировка — комнаты-прямоугольники: общая грань даёт одну внутреннюю стену, перекрытие сливает комнаты; двери и окна — проёмы в стенах. Диагональные стены не поддерживаются.
- Вид: макет на макетном коврике (сетка, деления, транспортир), белые панели «из пенокартона», жёлтый цвет инструмента, веер образцов краски для выбора цвета. Шрифты Sofia Sans Condensed, Geologica, JetBrains Mono.
- Каталог: Kenney Furniture Kit (CC0), 124 модели. Свои модели: GLB, glTF, FBX, OBJ, STL, DAE, PLY, 3MF, ZIP.
- Денису приложение отдаётся страницей-артефактом Claude; позже — программа для Windows из той же сборки.

## Consequences

- Брать чужой код и модели можно только с подходящей лицензией (MIT, CC0 и подобные); из `pascalorg/editor` код не копировался.
- Прямая загрузка по ссылке Sketchfab требует входа в аккаунт Sketchfab; пока модель скачивают и перетаскивают файлом или архивом.
- ИИ-функции (GLM): ключ нельзя класть в страницу; нужен отдельный шаг с вводом ключа пользователем или возможностью артефакта `sample`.
