# 2026-11-01 Код игры в GitHub, синхронизация в Studio через Rojo

## Context

- Claude работает в облачной сессии без доступа к Roblox Studio. Официальный MCP-сервер Studio работает только локально, поэтому из облака недоступен.
- У Дениса есть Windows-ПК со Studio, на него можно ставить программы. Подключить MCP или API к Studio с этого ПК не получится.
- API-ключа Roblox Open Cloud нет, домен `apis.roblox.com` заблокирован сетью облачного окружения.
- Контейнер облачной сессии временный: всё, что не запушено, пропадает.

## Options

- Rojo + GitHub: код в репозитории, Rojo переносит его в Studio. Плюсы: код не теряется, обновления не затирают карту, не нужно вручную передавать файлы. Минусы: разовая настройка ПК; скрипты нельзя править в Studio.
- Файлы `.rbxlx`: Claude собирает файл плейса, пользователь скачивает и открывает. Плюсы: ничего не ставить. Минусы: каждый новый файл затирает ручные правки карты, история не хранится.
- Open Cloud API: публикация плейса напрямую. Отложено: нет ключа и доступа к домену.

## Decision

Rojo + GitHub. Выбор Дениса, 2026-11-01.

## Consequences

- Positive: код и история в GitHub; карта в Workspace в безопасности; обновления одной командой `update.cmd`.
- Negative: скрипты в Studio не правятся (Rojo перезапишет); автотестов нет, проверка через Output в Studio.
- Follow-up: настройка ПК по `docs/SETUP_PC.md` в репозитории игры; выбрать жанр игры (см. [[60_Tasks/Task_Log]]).
