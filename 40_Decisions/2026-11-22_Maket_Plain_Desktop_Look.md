# 2026-11-22 «Макет»: вид обычной настольной программы вместо «макетной мастерской»

## Context

- 2026-11-22, после выпуска 0.3.0, Денис написал: «слишком иишно выглядит анимация да и в целом видно что приложение ии делал (из-за шрифтов, специфического расположения), надписи "готово" и тому подобного».
- До этого вид был задуман как «макет на макетном коврике» ([[40_Decisions/2026-11-22_Maket_3D_Design_App]]): подгружаемые шрифты Sofia Sans Condensed, Geologica и JetBrains Mono, плавающие белые панели поверх сцены, жёлтая «лента», транспортир и деления на коврике, веер образцов краски. В обучении были штамп «ГОТОВО», рисованная рука, метки по углам, лента прогресса и рисованная заставка.
- Толкование Claude (не слова Дениса): выдаёт не один элемент, а сама «придуманная тема» — необычные шрифты, нестандартное расположение и декоративные подписи вместе читаются как работа ИИ. Денису привычнее интерфейс, похожий на обычные программы.

## Options

- Поправить отдельные места: убрать штамп, заменить шрифты. Остаётся «специфическое расположение», которое Денис назвал прямо.
- Перейти на вид обычной настольной программы: привычная раскладка, системный шрифт, без украшений. Выбрано.

## Decision

Решение принял Claude по замечанию Дениса (Денис просит решать самому). Версия 0.4.0:

- Раскладка как в привычных редакторах: строка меню («Файл», «Правка», «Вид», «Справка»), панель инструментов, каталог слева (поиск и выбор раздела), свойства справа, строка состояния внизу, обычные окна-диалоги. На телефоне — одна панель под сценой, переключается вкладками.
- Шрифт системный (`Segoe UI`, `system-ui`), файлы шрифтов из проекта удалены. Серые нейтральные панели, один синий цвет выделения `#0f6cbd`, скругления до 4px. Надписей заглавными буквами нет.
- Сцена: светлый нейтральный фон с сеткой по умолчанию (`light`), без печати на коврике, рамки и транспортира; выделение синее. Прежние цвета фона остались в свойствах сцены; сохранённый зелёный фон один раз меняется на светлый (ключ `maket.look`).
- Цвет выбирается сеткой образцов прямо в панели свойств (вместо веера); сочетания цветов остались.
- Обучение: небольшое окно с номером шага, тонкой полосой хода, короткой настоящей записью экрана (`public/tour/<шаг>-<язык>.mp4`), заголовком и текстом. Отметка в сцене — простая рамка или точка. Шаг по-прежнему засчитывается по сделанному действию. Штампа, руки, меток и заставки нет.
- Тексты переписаны будничным тоном, без лозунгов.

## Consequences

- Правило вида записано в `CLAUDE.md` репозитория кода: не добавлять подгружаемые шрифты, декоративные элементы, градиенты, стекло, надписи заглавными, восторженные подписи.
- Записи для обучения снимает `scripts/clips.mjs` с собранного приложения; после заметной смены вида их нужно переснять (`npm run build && npm run clips`, нужен ffmpeg).
- Пункт «Вид» в [[40_Decisions/2026-11-22_Maket_3D_Design_App]] заменён этим решением.
- Для этого пользователя «своеобразный авторский стиль» — риск, а не достоинство: см. [[01_Index/User_Working_Profile]].
